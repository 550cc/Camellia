# 小窗补丁 · 跨版本适配（A 路线）

> 目标：让 HyperOS 桌面长按菜单「小窗」项补丁覆盖**任意版本**，不依赖版本表、不硬编码地址。
> 路线：Dart AOT 运行时指令补丁（native 探针 + LSPosed 注入），不改 APK。

## 关键事实速查

### v18 的硬编码（必须全部推翻）
```c
#define APK_ELF_OFF   0x1a1c000UL   /* libapp.so 在 base.apk 内偏移 */
#define TARGET_VADDR  0x19e737cUL   /* isValid 函数虚拟地址 */
#define EXPECT_APK_OFF 0x340337CUL  /* 对应 APK 文件偏移 */
#define PATCH_LEN     12
```

### v18 的补丁内容（12 字节）
```
原序言: fd79bfa9 fd030faa ef0101d1
补丁后: c0820091 c0035fd6 1f2003d5
        add x0,x22,#0x20 ; ret ; nop
```

### 已验证事实
- **7.50 系不适用本方案**：无 `libapp.so`（旧 Java 架构，只有 filament 3D 库）。
  范围收窄为 **8.01 系（Flutter/Dart AOT）**
- 49 个 8.01 系版本，`isValid` 前 12 字节**完全一致**：`fd79bfa9fd030faaef0101d1`
  —— 但这 12 字节在 libapp.so 中出现 **约 2000 次**，**绝不能单独作定位锚**（已证伪）
- 旧精确模板（256/305 条）跨版本：score 0.664–0.785，second 0.066–0.074，ratio 9.8–10.6
- **新：256 条数据驱动掩码模板**（保留 85% 位，0 个全通配 word）
  → **49/49 唯一命中、其余 ~1965 候选 0 命中（ratio = ∞）**，且不需要版本表
  → 详见 `03-掩码定位方案.md`
- 补丁实测生效过（用户确认"测试添加成功了"），但**后来消失**

### 根因（本次最重要的发现）
HyperOS 的 **XYRE 内存清理**会对代码页发 `madvise(MADV_DONTNEED)`，
丢弃被 COW 修改的代码页 → **补丁静默回滚，无任何报错**。
→ 必须实现 madvise guard，否则任何补丁都可能在数分钟后消失。
